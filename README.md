# YORU Bakes

Template landing page responsif, HTML/CSS/JavaScript tanpa framework. Jalankan `npm run dev`, lalu buka http://127.0.0.1:4173. Build statis: `npm run build`.

Logo asli ada di `assets/`. Foto ilustrasi dari Unsplash; ganti dengan foto produk asli sebelum digunakan untuk penjualan. Warna krim dan espresso merupakan interpretasi desain dari aset logo monokrom, bukan palet resmi yang diberikan.

Menu, harga, dan cerita adalah contoh. Ubah array `items` di `app.js` untuk katalog; ubah `index.html` untuk konten. Keranjang hanya simulasi selama halaman terbuka, tanpa checkout atau pengiriman pesanan. Tombol salin memerlukan localhost/HTTPS dan izin clipboard browser. Logo digunakan dari `yoru Just Text.svg` pada latar terang; semua SVG sumber lainnya disimpan tanpa perubahan.

Efek kedalaman memakai CSS perspective, transform 3D, parallax scroll, dan hover tilt. Tidak menggunakan model WebGL. Preferensi reduced motion dihormati.
